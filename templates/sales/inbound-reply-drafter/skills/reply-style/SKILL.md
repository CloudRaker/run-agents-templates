# Reply style

Edit the values in angle brackets for your company.

## Template

```
Hi <first name>,

Thanks for your message about <their topic in a few words>.

<One or two sentences that answer their question at a high level.>

The best next step is a 20-minute call. Book a time here: <booking link>

<signature>
```

## Rules

- Use a maximum of 90 words, without the signature.
- Use the first name of the sender. If you do not know it, use "Hi there".
- Answer the real question in one or two sentences. Do not paste product marketing.
- Write in the language of the sender.
- Use no more than one link: the booking link.

## Pricing questions

Use this sentence: "Pricing depends on your volume and setup, so we confirm it on a short call."

## Contact paths for other requests

| Request             | Answer                                     |
| ------------------- | ------------------------------------------ |
| Support             | "Our support team helps at <support email>." |
| Jobs                | "See our open roles at <careers page>."      |
| Partners            | "Write to <partners email>."                 |

## Signature

```
<Name>
<Title>, <Company>
```
