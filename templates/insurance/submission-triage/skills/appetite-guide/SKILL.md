# Appetite guide

The values below are placeholders. Your underwriting team replaces them with the real appetite before the first run.

Apply the rules in this order. The first rule that matches gives the result. Record each rule that matched as a reason.

## Out (decline)

| Rule                | Placeholder value                                                  |
| ------------------- | ------------------------------------------------------------------ |
| Excluded classes    | Fireworks, demolition, crypto mining, cannabis cultivation         |
| Excluded states     | Any state outside the list in "Target states"                      |
| Revenue too high    | Annual revenue above 50,000,000                                    |
| Loss ratio too high | 5-year incurred losses above 100 percent of 5-year premium         |
| Large loss          | One claim with an incurred amount above 1,000,000 in the last 5 years |

## Refer (underwriter decides)

| Rule                  | Placeholder value                                               |
| --------------------- | --------------------------------------------------------------- |
| Refer classes         | Roofing, trucking, habitational over 100 units, food processing |
| Revenue band          | Annual revenue from 20,000,000 to 50,000,000                    |
| Loss ratio            | 5-year loss ratio from 60 to 100 percent                         |
| Open claims           | 3 or more open claims                                           |
| Loss history too short | Fewer than 3 years of loss runs                                |
| New venture           | Less than 3 years in business                                   |

## In (target)

All other submissions in a target class and a target state.

Target classes: offices, light manufacturing, retail, wholesale distribution, professional services.

Target states: AZ, CO, GA, IL, NC, OH, PA, TX, VA.

## How to state a reason

Write one line for each reason, with the rule and the value from the submission. Example: "Refer: revenue band, annual revenue 32,000,000."
