# Call scorecard

Give each criterion a score from 0 to 5. Quote the transcript for each score.

## Greeting

| Score | Use it when                                                              |
| ----- | ------------------------------------------------------------------------ |
| 5     | The agent gives the company name, the agent name and an offer of help.   |
| 3     | The agent greets the caller, but one of the three parts is missing.      |
| 0     | There is no greeting.                                                    |

## Empathy

| Score | Use it when                                                                   |
| ----- | ----------------------------------------------------------------------------- |
| 5     | The agent repeats the problem in their own words and acknowledges the impact. |
| 3     | The agent acknowledges the problem, but with a generic phrase only.           |
| 0     | The agent interrupts, blames the caller or ignores the impact.                |

## Resolution

| Score | Use it when                                                                    |
| ----- | ------------------------------------------------------------------------------ |
| 5     | The problem is solved on the call, and the agent confirms it with the caller.  |
| 3     | The agent gives a clear next step, an owner and a time.                        |
| 0     | The call ends with no answer and no next step.                                 |

## Compliance phrases

The agent must say each phrase, or a phrase with the same meaning:

- A confirmation of the caller identity before account details.
- "Is there anything else I can help you with?"
- A closing with the ticket reference, when a ticket exists.

Give 5 when all phrases are present. Remove 2 for each missing phrase. The minimum is 0.

## Rules

- Score what the transcript shows. Do not guess the tone of the voice.
- A score without a quote is not valid. If you cannot find a quote, give 0 and explain.
