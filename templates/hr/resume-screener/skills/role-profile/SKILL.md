# Role profile

Edit this file for your open role before you use the agent.

## Role

- Title: Senior backend engineer
- Team: Platform
- Location: Remote

## Must have (each missing item removes 20 points)

- 5 or more years of professional software work.
- Production work with one backend language: Go, Java, Python or TypeScript.
- Work with a relational database.

## Nice to have (each match adds 5 points, maximum 25)

- Work with a cloud provider.
- Work with message queues or event streams.
- Mentoring or team lead work.
- Open source contributions.
- Work in a regulated industry.

## Scoring

1. Start at 60.
2. Apply the must-have and nice-to-have rules.
3. Keep the score between 0 and 100.
4. Recommendation: `interview` for 75 or more, `maybe` for 50 to 74, `no_match` for less than 50.

## Never use

Age, gender, race, ethnicity, religion, disability, marital or family status, pregnancy, nationality, sexual orientation, photos, names as a signal, or gaps in employment without context.
