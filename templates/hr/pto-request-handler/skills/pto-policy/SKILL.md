# Time-off policy

Edit this policy for your company before you use the agent.

## Types

| Type       | Notice                      | Maximum in one request |
| ---------- | --------------------------- | ---------------------- |
| vacation   | 10 workdays before the start | 15 workdays           |
| personal   | 2 workdays before the start  | 3 workdays            |
| sick       | No notice                    | 5 workdays            |
| parental   | Contact the people team      | Not handled here      |

## Rules

- A workday is Monday to Friday. Company holidays do not count.
- Company holidays this year: edit this list, for example 2026-12-25 and 2027-01-01.
- Blackout periods: edit this list, for example the last 5 workdays of each quarter for finance roles.
- A request that breaks a rule is still possible. The manager decides. Flag the rule in the summary.
- Parental, medical and other long leaves go to the people team. Do not create an event for them.
