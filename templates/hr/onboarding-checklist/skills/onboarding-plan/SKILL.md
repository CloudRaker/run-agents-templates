# Onboarding plan

Edit this list for your company. A negative offset is before the start date. Day 0 is the start date.

| Offset | Owner    | Task                                                        |
| ------ | -------- | ----------------------------------------------------------- |
| -10    | hr       | Send the welcome email and the first-day agenda             |
| -10    | hr       | Collect the signed contract and the tax forms               |
| -7     | it       | Order the laptop and ship it to the new hire                |
| -3     | it       | Create the accounts: email, chat, code hosting, HR system   |
| -3     | manager  | Select an onboarding buddy                                  |
| -1     | manager  | Prepare the 30-60-90 day goals                              |
| 0      | manager  | First-day meeting with the team                             |
| 0      | new_hire | Complete the security training                              |
| 0      | new_hire | Read the employee handbook                                  |
| 2      | hr       | Benefits enrollment session                                 |
| 5      | manager  | End of week 1 check-in                                      |
| 30     | manager  | 30-day review                                               |
| 90     | hr       | 90-day survey                                               |

## Owners

- `hr`: the people team member who runs onboarding. Edit: `people@example.com`.
- `it`: the IT owner. Edit: `it@example.com`.
- `manager`: the manager from the input.
- `new_hire`: the new hire. Assign only when the new hire has an Asana account.

## Project

Create the tasks in the Asana project named `Onboarding`.

## Role additions

- Engineering roles: add "Set up the development environment" for `new_hire` at day 1, and "Give repository access" for `it` at day -3.
- Sales roles: add "Give CRM access" for `it` at day -3.
