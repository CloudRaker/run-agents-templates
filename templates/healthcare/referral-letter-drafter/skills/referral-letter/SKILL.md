# Referral letter

## Structure (in this order)

1. Header: the date, "DRAFT: For review, not signed", the specialist name, specialty, practice and address.
2. Subject line: "Referral: <patient name>, date of birth <YYYY-MM-DD>". Add "Urgent" first when urgency is `urgent`.
3. Opening: one sentence with the reason for the referral and the clinical question.
4. Relevant history: three to six short points. Only facts that relate to the reason.
5. Current medications and allergies: one line each. Write "No known allergies" only when the summary says so.
6. Recent results: tests and dates from the summary.
7. Request: what you ask the specialist to do, for example "assess and advise" or "assess and treat".
8. Close: contact details placeholder and the signature block of the referring clinician, with no signature.

## Checklist

| Check                         | Rule                                                          |
| ----------------------------- | ------------------------------------------------------------- |
| Clinical question             | The opening states one clear question.                        |
| Facts                         | Each fact comes from the input. Nothing added.                |
| Doses                         | Copied as written. No unit conversion.                        |
| Length                        | One page. A maximum of 350 words.                             |
| Tone                          | Professional, plain words, no abbreviations without a meaning. |
| Urgency                       | `urgent` states the reason for the urgency in the opening.    |
